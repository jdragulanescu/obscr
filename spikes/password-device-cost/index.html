Interpretation limits

Cold means a fresh worker, not cleared disk or network caches. Cold includes transfer and startup. Browser heap values exclude some worker, native and WASM memory. Missing memory is null. Pixel buffers represent an RGBA carrier, not a selected complete format. Allocation failure is injected, not real OOM. Desktop runs do not establish phone support.
